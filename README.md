# ☁️ Moshify — Cloud Hosting Landing Page

**Moshify** — современный лендинг для хостинг-провайдера, созданный для демонстрации тарифных планов, преимуществ и отзывов клиентов.  
Проект разработан в учебных целях и вдохновлён профессиональными промо-сайтами веб-хостингов.

🌐 **Онлайн-версия:** [mymosh.netlify.app](https://mymosh.netlify.app/)

---

## ✨ Основные разделы

- 💡 **Главная страница:** Промо-блок и кнопка “Get Started”  
- 💰 **Тарифные планы:** Entry-планы с ценами, характеристиками и кнопками покупки  
- ⚙️ **Преимущества:** Информация о быстродействии, WordPress-интеграции и лёгкости управления  
- 🧠 **Панель управления:** Визуальный блок с описанием возможностей  
- 💬 **Отзывы клиентов:** Цитаты и имена пользователей  
- 📞 **Футер:** Контактные ссылки и копирайт

---

## 🧱 Используемые технологии

| Технология | Назначение |
|-------------|-------------|
| **HTML5** | Структура страницы |
| **CSS3 (Flexbox/Grid)** | Адаптивная верстка |
| **JavaScript** | Интерактивность и динамика контента |
| **Netlify** | Хостинг и деплой |
